Which Mac do you have?

Macs made from late 2020 onward run on Apple Silicon (M1, M2, M3, M4). Older ones have an Intel chip. They need different downloads — the wrong one simply won't open.

We ask your graphics chip, because every Mac browser claims to be “Intel” whatever the hardware. It’s right on almost every Mac, but if Litranite won’t open, try the other build.

Or check it yourself — it's two clicks+

Click the apple menu in the top-left corner of your screen, then About This Mac. A small window opens:

3

Open it the first time — the part everyone gets stuck on

Litranite isn't notarized by Apple yet (that costs $99 a year, and we're two students), so macOS stops it the first time. Nothing is wrong with the app. Try these in order — most people only need the first.

a.  In Finder › Applications, right-click (or Control-click) Litranite and choose Open. In the box that appears, click Open again. Double-clicking will not work — it has to be the right-click menu.

b.  If there was no Open button, go to menu › System Settings › Privacy & Security, scroll down, and click Open Anyway next to the message about Litranite. (On macOS 12 and older: System Preferences › Security & Privacy › General.)

c.  If macOS insists Litranite “is damaged and can't be opened”, one command clears the quarantine flag. Press ⌘ + Space, type Terminal, hit Return, then paste this and press Return:

➜ xattr -cr /Applications/Litranite.app

Nothing visible happens — no output, no confirmation. That's exactly right. Now open Litranite normally.

If something still goes wrong

The exact words macOS shows you, and what each one means.

“Litranite is damaged and can't be opened. You should move it to the Bin.”+
The most common one, and it's misleading — the app is fine. macOS marks anything downloaded from the internet and refuses unsigned apps outright. Run step 3c above: xattr -cr /Applications/Litranite.app. If it still says this, you very likely have the wrong build for your chip — see the next answer.
Nothing happens at all when I open it+
The icon bounces once, or nothing happens — that's usually the Apple Silicon build on an Intel Mac. Go back to Which Mac do you have?, check the chip, and download the other build. Dragging the new one into Applications will ask to replace the old one; say yes.
“Apple cannot check it for malicious software”+
This is the normal notice for an app that isn't notarized. Right-click the app and choose Open (step 3a), or use Open Anyway in System Settings (step 3b). Both give you a one-time exception; after that it opens like any other app.
Terminal says “No such file or directory”+
The app isn't in your Applications folder yet — the command looks for it there. Drag Litranite from the disk-image window into Applications first (step 2), then run the command again. Also check you pasted the whole line, including /Applications/.
The .dmg won't open, or says the image isn't recognised+
Usually a download that stopped halfway. Delete the file and download it again, and let it finish before opening — a file ending in .dmg.download is still arriving. If your browser unzipped it into something odd, try downloading with Safari.
Can I use the Intel build on an M1/M2/M3 Mac?+
Yes — Apple Silicon Macs can run Intel apps through Rosetta, and macOS offers to install it the first time. It works, but it's slower and heavier on battery than the Apple Silicon build, so only do this if the other one gives you trouble. The reverse doesn't work: an Intel Mac can't run the Apple Silicon build at all.
Which macOS do I need?+
macOS 10.15 Catalina or newer, on both chips. You'll find your version in the same About This Mac window.
Where did the app go after I dragged it?+
Into Applications. Open Finder and click Applications in the sidebar, or press ⌘ + Space and type Litranite. To keep it in the Dock, open it and then right-click its Dock icon → Options › Keep in Dock.
How do I uninstall it?+
Drag Litranite from Applications to the Bin. Your notes and annotations stay on your Mac in ~/Library/Application Support/com.litranite.app, so you can delete that folder too if you want everything gone. Export a backup first if you might come back.
Still stuck+
Email litranite@gmail.com with your chip (Apple Silicon or Intel), your macOS version, and the exact words of the message you're seeing. A screenshot helps most of all — press ⌘ + Shift + 4 and drag over the box.
